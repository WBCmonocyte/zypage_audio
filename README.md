# Zypage Audio Donate

Chrome/Edge extension (Manifest V3): kéo file audio vào phần **Ghi âm** trên trang donate Zypage thay vì ghi bằng micro.

## Cài đặt

1. Mở `chrome://extensions` (hoặc `edge://extensions`).
2. Bật **Developer mode**.
3. **Load unpacked** và chọn thư mục này.

## Cách dùng

1. Mở trang donate Zypage, chọn tab **Ghi âm**.
2. Kéo file `.webm`, `.ogg`, `.mp3`, `.wav`, `.m4a`… vào ô ghi âm, hoặc bấm **chọn file**.
3. Nghe thử, rồi bấm xác nhận như donate ghi âm bình thường.

File không được dài hơn giới hạn của trang (thường 30 giây). `mp3`/`wav` được chuyển sang định dạng trình duyệt hỗ trợ trước khi upload.
